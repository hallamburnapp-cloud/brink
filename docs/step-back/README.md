# The step back (7 October 2026)

The owner said: "I just still don't like it. I don't think it's the kind of game that works properly for what we want it to do. Take a step back, and redo this again to be exceptional." This folder is the record of the panel that ran before anything was rebuilt: four critiques of the night as shipped (v0.3.0), six concepts, three judges, one synthesis. HOTEL.md is what was built from it.

- `critiques.md` — four lenses on the night as it was (casual player, product, designer, UX).
- `concepts.md` — six directions, each a complete pitch with the first sixty seconds and the screen.
- `judges.md` — three judges (publisher, player, designer) scoring the six and naming grafts.
- `synthesis.md` — the diagnosis, the recommendation, the runner-up, and the one question for the owner.
